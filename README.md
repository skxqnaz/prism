### ⬇️ Installation
1. Télécharge **PRISM-Setup-1.0.0.exe** ci-dessous
2. Lance-le. Si Windows affiche *« Windows a protégé votre ordinateur »* → **Informations complémentaires** → **Exécuter quand même** (l'appli n'est pas encore signée)
3. Clic droit sur une vidéo → **Ouvrir avec → PRISM**

### ✨ Ce qu'il sait faire
- **Tous les formats** : MKV, MP4, AVI, MOV, WEBM, TS/M2TS, WMV, FLV, MPG, VOB…
- **Tous les codecs** : H.264, HEVC / x265 10 bits, AV1, VP9, MPEG-2, DivX — HDR adapté à ton écran
- **Tout le son** : DTS, TrueHD, EAC3, AC3, FLAC…
- **Sous-titres** : SRT, ASS, VTT et PGS (Blu-ray), chargés automatiquement, style et décalage réglables
- **Conversion invisible** : lecture directe si possible, sinon ta carte graphique (AMD, NVIDIA, Intel) convertit en temps réel
- Aperçu au survol de la timeline, chapitres, pistes VF/VO
- Lumière d'ambiance, volume jusqu'à 200 %, reprise à la seconde près
- File d'attente du dossier, captures PNG, image dans l'image, raccourcis clavier

### 💻 Configuration
Windows 10 / 11 — 64 bits

### 🔒 Gratuit et respectueux
Pas de pub, pas de compte, rien n'est envoyé : ton historique reste sur ton PC.
